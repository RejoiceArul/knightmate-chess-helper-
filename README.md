# knightmate-chess-helper
Knightmate is a Chrome extension that analyzes chess positions locally using Stockfish, displays move suggestions, and offers configurable autoplay, playing strength, mistakes, and a fast Bullet mode. No account, subscription, or analysis server required.



How to use it:

Install Knightmate in Chrome
1. On the GitHub repository page, click Code → Download ZIP. GitHub packages the uploaded files automatically.
2. Unzip the download.
3. Open Chrome and go to chrome://extensions.
4. Turn on Developer mode in the top-right corner.
5. Click Load unpacked.
6. Select the extracted folder containing manifest.json. If it’s inside another Knightmate folder, select that inner folder.
7. Refresh your chess.com tabs.
8. Pin Extension
9. It starts working once you enter chess.com
Keep the extracted folder on your computer, and disable older copies of the extension.

Note: 

This only works for chess.com currently.
